# Ireadbook — สเปกการออกแบบ

วันที่: 2026-10-26

## 1. จุดประสงค์
**ช่วยคนที่อยากอ่านหนังสือ แต่เริ่มยากและอ่านไม่ต่อเนื่อง ให้ได้อ่านหนังสือเล่มจริงที่ตัวเองมีอย่างสม่ำเสมอ และภูมิใจกับความคืบหน้าของตัวเอง**

แยกเป็น 3 เป้าหมาย:
1. **เริ่มอ่านได้ง่าย** — ลดแรงต้านก่อนอ่าน (เลือกเล่มไม่ถูก, ขี้เกียจ, คิดว่าต้องอ่านนาน)
2. **อ่านต่อเนื่อง** — อ่านทีละน้อยแต่บ่อย ไม่ล้มเลิกเมื่อพลาดไปบางวัน
3. **เห็นและภูมิใจกับความคืบหน้า** — ตัวเลข ชั้นหนังสือที่เต็มขึ้น และแชร์ได้

แอปไม่ได้ให้อ่านหนังสือในแอป — ผู้ใช้อ่านเล่มจริง แอปเป็นตัวช่วยและบันทึก

**วงจรหลัก:** เลือกเล่ม → อ่าน → บันทึก → เห็นความคืบหน้า → กลับมาอ่านอีก
ทุกฟีเจอร์ต้องตอบได้ว่าช่วยเป้าหมายข้อไหน ถ้าตอบไม่ได้ ตัดออก

**กฎที่ใช้ตัดสินใจ:**
- จากเปิดแอปถึงเริ่มจับเวลาไม่เกิน 2 แตะ ปุ่ม "อ่านต่อ" ใช้ได้ทันที ไม่ต้องรอห้อง 3D โหลด
- จากติดตั้งแอปถึงเริ่มอ่านรอบแรกไม่เกิน 2 นาที
- การเพิ่มหนังสือต้องเร็ว ไม่ทำให้ผู้ใช้เหนื่อยก่อนได้อ่าน
- ไม่ลงโทษผู้ใช้ (พลาดวัน เลิกอ่านเล่มที่ไม่ชอบ เป็นเรื่องปกติ)
- ความสวยงามช่วยให้อยากเปิดแอป แต่ต้องไม่ขวางการเริ่มอ่าน

## 2. ขอบเขตและข้อจำกัด
- ใช้คนเดียว ไม่มีล็อกอิน ไม่มีฟีเจอร์เพื่อน/ออนไลน์
- ข้อมูลทั้งหมดอยู่ในเครื่อง ใช้งานออฟไลน์ได้ อินเทอร์เน็ตใช้เมื่อมี (ดึงข้อมูลหนังสือ)
- ย้ายเครื่องด้วยไฟล์สำรอง (ส่งออก/นำเข้า)
- ใช้บนมือถือเป็นหลัก ใช้บนคอมได้
- สลับภาษาได้ ไทย/อังกฤษ (ทั้งหน้าจอ ข้อความ และพรอมต์ AI) ค่าเริ่มต้นตามภาษาเครื่อง
- ไม่รวม: ห้องที่เปลี่ยนตามการอ่าน, ข้อความแนวกวน/ตลก (ข้อความในแอปใช้ภาษาเรียบง่าย ชัดเจน)

## 3. เทคโนโลยี
- PWA: React + Vite + TypeScript
- 3D: Three.js (ผ่าน react-three-fiber)
- เก็บข้อมูล: IndexedDB (ผ่าน Dexie) รวมรูปภาพ
- สแกนบาร์โค้ด: ZXing (ในเครื่อง)
- อ่านตัวหนังสือบนปก: Tesseract.js ภาษาไทย+อังกฤษ (ในเครื่อง)
- ข้อมูลหนังสือ: Google Books API, Open Library (เมื่อมีเน็ต)
- แอนิเมชัน: Framer Motion (สปริง) / เสียง: สังเคราะห์ด้วย Web Audio API (ไม่ต้องมีไฟล์เสียง ใช้ออฟไลน์ได้)
- หลายภาษา: i18next (ไฟล์ข้อความแยก th.json / en.json)
- โฮสต์: Netlify หรือ GitHub Pages (ฟรี)

## 4. หน้าจอ (แถบเมนูล่าง 5 ปุ่ม)
**เปิดแอปครั้งแรก:** เลือกภาษา → เลือกห้อง → เพิ่มหนังสือ 1 เล่ม (หรือข้ามไปก่อน) → ตั้งเป้ารายวันเล็กๆ (5/10/15 นาที, ค่าเริ่มต้น 5) → เสนอให้เริ่มอ่านรอบแรกเลย
1. **ชั้นหนังสือ (หน้าแรก)** — ห้อง 3D เต็มจอ, ที่วาง "กำลังอ่าน" ด้านหน้า พร้อมปุ่มอ่านต่อ, เรียง/กรอง/ค้นหา, สลับมุมมอง 2D, แตะเล่ม → เลื่อนออกมา หมุนดู → รายละเอียด/เริ่มอ่าน
2. **อ่าน** — ระบบแนะนำเล่มให้ (เล่มที่กำลังอ่านล่าสุด), จับเวลา (ปกติ / แค่ 5 นาที / Pomodoro / คว่ำมือถือ), สรุปครั้งก่อน, เวลาที่เหลือจะจบเล่ม, จบรอบ → กรอกหน้า + โน้ตสั้น → XP → การ์ดแชร์; ปุ่มกรอกย้อนหลัง
3. **เพิ่มหนังสือ** — ถ่ายปกหน้า → ปกหลัง (ข้ามได้) → ครอป 4 มุม (ระบบหามุมให้ก่อน) → ระบบเดาข้อมูล → ตรวจ/แก้ → บันทึก
   - **โหมดเพิ่มต่อเนื่อง** สำหรับคนมีหนังสือหลายเล่ม: ถ่ายเล่มต่อไปได้ทันที ระบบเดาข้อมูลเบื้องหลัง แล้วตรวจทีหลังทีเดียว
   - เพิ่มแบบพิมพ์ชื่อค้นหา หรือกรอกเองโดยไม่ถ่ายรูปก็ได้
4. **สถิติ** — streak + ปฏิทิน, XP/เลเวล, อชีฟเมนต์, เป้ารายปี, สรุปรายเดือน/ปี, Wrapped
5. **ผู้ช่วย AI** — เทมเพลตพรอมต์ + รูปรวมปก, ปุ่มสุ่มเล่ม
- **ตั้งค่า** — ภาษา, ธีม/ปรับแต่งห้อง, คุณภาพกราฟิก, เสียง, เป้าหมาย, การแจ้งเตือน, ส่งออก/นำเข้า

## 4.1 รายละเอียดการจับเวลา
- เก็บเวลาเริ่ม แล้วคำนวณจากนาฬิกา จับเวลาต่อได้แม้ปิดจอหรือสลับแอป
- โหมดคว่ำมือถือ: จอต้องเปิดค้างไว้ (Wake Lock) แต่แสดงจอดำ ประหยัดแบต; หยิบขึ้นมา = หยุดชั่วคราว
- ลืมหยุดจับเวลา: ถ้าเกิน 3 ชม. หรือกลับมาเปิดแอปทีหลัง ให้ถามและแก้เวลาได้
- แก้ไข/ลบรอบที่บันทึกแล้วได้
- หนังสือที่ไม่มีเลขหน้าชัด (ebook/audiobook) ใช้เป็นเปอร์เซ็นต์แทนได้
- วันที่นับเป็น streak: อ่านครบเป้ารายวัน (ค่าเริ่มต้น 5 นาที) ตัวช่วย streak ใช้ได้เดือนละ 2 วัน

## 4.2 การเตือนให้อ่าน
PWA แบบออฟไลน์ตั้งการแจ้งเตือนตามเวลาเองได้ไม่แน่นอน (โดยเฉพาะ iPhone) จึงใช้วิธีนี้แทน:
- สร้างไฟล์ปฏิทิน (.ics) เตือนทุกวันตามเวลาที่เลือก เพิ่มเข้าแอปปฏิทินของเครื่อง
- ในแอปแสดงสถานะวันนี้ (อ่านแล้ว/ยัง) ชัดเจนที่หน้าแรก

## 5. การเพิ่มหนังสือ (ลำดับการเดาข้อมูล)
1. สแกน ISBN จากปกหลัง → ค้น Google Books → Open Library
2. ไม่เจอ/ไม่มีเน็ต → OCR ปกหน้า+หลัง เดาชื่อ/ผู้แต่ง/สำนักพิมพ์ (และค้นด้วยข้อความถ้ามีเน็ต)
3. ผู้ใช้แก้ได้ทุกช่อง; เล่มที่บันทึกตอนออฟไลน์ติดป้าย "รอเติมข้อมูล" แล้วลองใหม่เมื่อออนไลน์
4. เดาซีรีส์: จากข้อมูล API, รูปแบบ "เล่ม N / Vol. N / N" ในชื่อ, ผู้แต่งเดียวกัน+ชื่อคล้าย → ถามยืนยัน
5. รูปปก: ผู้ใช้ปรับ 4 มุม → ดัดภาพให้ตรง (perspective warp) → ปรับแสง/สีอัตโนมัติ → ดึงสีหลักไว้ทำสันหนังสือ

## 6. ข้อมูล
**Book**: id, title, originalTitle, subtitle, authors[], translators[], publisher, isbn, year, language, pageCount, format (ปกอ่อน/ปกแข็ง/ebook/audiobook), genre (แนวหลัก), tags[], seriesId, seriesIndex, coverFront, coverBack, spine (รูป, ไม่บังคับ), cropPoints, dominantColor, status (อยากอ่าน/กำลังอ่าน/พักไว้/จบแล้ว/เลิกอ่าน), currentPage, rating, review, whyRead, recommendedBy, acquiredAt, startedAt, finishedAt, rereadCount, needsLookup, createdAt, updatedAt
**Series**: id, name, totalVolumes (ถ้ารู้)
**Session**: id, bookId, startedAt, endedAt, durationSec, startPage, endPage, mode (timer/5min/pomodoro/facedown/manual), note, mood
**Quote**: id, bookId, page, text, photo, createdAt
**Achievement**: id, unlockedAt
**PromptTemplate**: id, name, body (มีตัวแปรเช่น {unreadBooks}), builtIn
**Settings**: theme, roomCustomization, quality, sound volumes, yearlyGoal, dailyGoalMin, reminders, streakFreezes

**ค่าคำนวณ:** ความเร็ว (หน้า/นาที ต่อเล่มและรวม) → เวลาที่เหลือจะจบ; streak = วันที่มีเซสชันติดกัน (ใช้ตัวช่วย streak ได้เดือนละ 2 วัน); XP = นาทีที่อ่าน + โบนัสจบเล่ม/อชีฟเมนต์

**ไฟล์สำรอง:** `.ireadbook` (zip: data.json + images/) มีเลขเวอร์ชันรูปแบบไฟล์; นำเข้าเลือก "แทนที่ทั้งหมด" หรือ "รวม" (ใช้ updatedAt ล่าสุด)

## 7. ห้อง/ธีม
แนวคิด: แต่ละธีมคือ "ห้องจริงของคนในโลกนั้น" ว่าเขาวางชั้นหนังสือไว้ยังไง ของรอบตัวเป็นแบบไหน แสงมาจากไหน
ไม่มีห้องไหนเป็นห้องหลัก — ผู้ใช้เลือกห้องแรกตอนเปิดแอปครั้งแรก และเปลี่ยนได้ตลอด

รายชื่อห้อง (เฟส 1 ทำห้องแรก 1 ห้อง ที่เหลือทยอยในเฟส 2):
- ห้องใต้หลังคาวันฝนตก — หลังคาลาด หน้าต่างกลม โคมไฟเหลือง (ห้องแรกในเฟส 1)
- Cyberpunk — ห้องเช่าแคบในเมืองนีออน ชั้นเหล็กไฟ LED ป้ายโฮโลแกรม
- ห้องสมุดเก่า — ชั้นสูงจรดเพดาน บันไดเลื่อนตามราง เทียน
- บ้านญี่ปุ่น — ชั้นไม้เตี้ย โชจิ สวนซากุระ
- บ้านต้นไม้ — ชั้นจากกิ่งไม้ หิ่งห้อยตอนกลางคืน
- สถานีอวกาศ — หนังสือยึดด้วยสายรัด หน้าต่างเห็นโลก
- หอคอยพ่อมด — ชั้นโค้งตามผนังหอกลม หนังสือบางเล่มลอย ขวดยา
- ตู้นอนรถไฟกลางคืน — ชั้นเล็กเหนือเตียง วิวเมืองผ่านหน้าต่าง
- ห้องใต้ทะเล — หน้าต่างกระจกโค้ง ปลาว่ายผ่าน แสงน้ำกระเพื่อม
- คาเฟ่มุมถนน — ชั้นข้างเคาน์เตอร์ กระจกเห็นคนเดินผ่าน
- สตูดิโอมินิมอล — ห้องขาวแดดลอดม่าน เบาเครื่องที่สุด

- ธีมเปลี่ยนทั้งแอป: สี ฟอนต์ เสียง ปุ่ม
- ปรับแต่ง: สี/วัสดุชั้น, จำนวนชั้น, กลางวัน/กลางคืน, ของตกแต่ง (บางชิ้นปลดล็อกจากอชีฟเมนต์)
- เรียงอัตโนมัติ: แนว, ซีรีส์ (วางติดกันเป็นชุด มีเลขเล่ม), ผู้แต่ง, สถานะ, วันที่เพิ่ม, สี; มีป้ายบอกโซน
- คุณภาพกราฟิก ต่ำ/กลาง/สูง (ตรวจสเปกเครื่องเพื่อตั้งค่าเริ่มต้น)

## 8. หน้าตาและความรู้สึก
- ไม่ใช้เลย์เอาต์สำเร็จรูป (header → การ์ดกริด → CTA → footer), ไม่ใช้ไล่สีม่วง-ฟ้า/การ์ดกระจกฝ้า/อีโมจิเป็นไอคอน
- ห้องเป็นพระเอกเต็มจอ ปุ่มโผล่ตามบริบท ความเด่นของแต่ละหน้าไม่เท่ากันโดยตั้งใจ
- ฟอนต์ไทย serif สำหรับหัวข้อ + sans อ่านง่ายสำหรับเนื้อหา
- แสงในห้องมีแหล่งหลักชัดเจน, ตัวหนังสือในฉากเป็นฟอนต์จริงอ่านออก
- แอนิเมชันสปริง, เปลี่ยนหน้าต่อเนื่อง (หนังสือลอยจากชั้นเป็นหน้ารายละเอียด), สั่นเบาๆ (Android)
- เสียง: กดปุ่ม, หยิบหนังสือ, พลิกหน้า, อชีฟเมนต์, บรรยากาศห้อง; ปิด/ปรับแยกประเภท
- ก่อนเขียนโค้ดหน้าจอสำคัญ ทำภาพตัวอย่าง 2–3 แบบให้ผู้ใช้เลือก

## 9. ผู้ช่วย AI (ตัวสร้างพรอมต์)
เทมเพลต: ควรอ่านเล่มไหนก่อน (รูปรวมปกมีหมายเลข + รายชื่อ ผู้แต่ง ISBN แนว หน้า ลำดับซีรีส์ + รสนิยมผู้ใช้ เวลาที่มี อารมณ์ → ขอให้ค้นรีวิว ดูคุณภาพ เรียงอันดับพร้อมเหตุผล), วางแผนให้อ่านจบตามวันที่, ทดสอบความเข้าใจ, สรุปโน้ต, เขียนเทมเพลตเอง
ปุ่มคัดลอกข้อความ + บันทึก/แชร์รูปรวมปก

## 11. ข้อจำกัดที่รู้ล่วงหน้า
- OCR ปกไทยแม่นไม่ 100% (ฟอนต์ตกแต่ง) — ผู้ใช้แก้ได้เสมอ
- ขอสิทธิ์เก็บข้อมูลถาวร (navigator.storage.persist) และเตือนให้สำรองข้อมูลทุก 2 สัปดาห์หรือทุก 10 เล่มใหม่
- iPhone: ต้องกดอนุญาตเซนเซอร์สำหรับโหมดคว่ำมือถือ, ไม่มีการสั่น, ถ้าไม่ได้ติดตั้งลงหน้าจอ Safari อาจลบข้อมูล → แอปเตือนให้ติดตั้งและสำรองข้อมูลเป็นระยะ
- ห้อง 3D หนัก → มีตัวเลือกคุณภาพและมุมมอง 2D
- การจับเวลาต้องอยู่รอดเมื่อปิดจอ/สลับแอป: เก็บเวลาเริ่มแล้วคำนวณจากนาฬิกา ไม่ใช้ตัวนับ

## 12. การทดสอบ
- ตรวจว่าทุกข้อความมีครบทั้ง th และ en
- Unit test: การคำนวณ streak, XP, ความเร็ว, เดาซีรีส์, ส่งออก/นำเข้า
- ทดสอบเส้นทางใช้งานจริงด้วย Playwright (เพิ่มหนังสือ → อ่าน → สถิติ → สำรอง → นำเข้า) ด้วยข้อมูลหนังสือไทย

## 13. เฟส
1. ระบบออกแบบ (ฟอนต์ สี แอนิเมชัน เสียง) + ระบบ 2 ภาษา + เพิ่มหนังสือ + ระบบห้อง (ห้องแรก: ห้องใต้หลังคาวันฝนตก) + มุมมอง 2D + จับเวลา/กรอกย้อนหลัง + streak + สำรองข้อมูล
2. ห้องอื่นๆ (ทยอยทีละห้อง เน้นคุณภาพ) + การปรับแต่งห้อง + ของตกแต่งที่ปลดล็อกจากการอ่าน + เรียงอัตโนมัติครบ
3. สถิติเต็ม (เล่มที่จบ นาที หน้า วันที่อ่าน ความเร็ว แนว ช่วงเวลาที่อ่านบ่อย) + XP/อชีฟเมนต์ (ประมาณ 20 อัน ที่มีความหมาย ไม่เฟ้อ) + การ์ดแชร์ + Wrapped
4. ผู้ช่วย AI + เก็บคำคม + สุ่มเล่ม
