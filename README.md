# Ireadbook

เว็บแอป (PWA) สำหรับคนที่อยากอ่านหนังสือเล่มจริงที่ตัวเองมีให้สม่ำเสมอ อ่านทีละนิดทุกวัน และภูมิใจกับความคืบหน้า
ใช้คนเดียว ไม่มีล็อกอิน ข้อมูลทั้งหมดอยู่ในเครื่อง ใช้ออฟไลน์ได้ และย้ายเครื่องด้วยไฟล์สำรอง

## ทำอะไรได้บ้าง

- **เพิ่มหนังสือจากรูปถ่าย:** ถ่ายปกหน้าและปกหลัง ลากมุมปกให้ตรง แล้วแอปจะทำต่อเองตามลำดับ
  1. ดัดภาพปกให้ตรง
  2. อ่านบาร์โค้ด ISBN
  3. ค้นข้อมูลจาก Google Books และ Open Library
  4. ถ้าค้นไม่เจอ จะอ่านตัวหนังสือบนปก (ไทย/อังกฤษ) แล้วเดาชื่อเรื่อง ผู้แต่ง และผู้แปล
  - แก้ไขข้อมูลได้ทุกช่อง
  - มีโหมดเพิ่มหลายเล่มต่อเนื่อง
  - ถ้าบันทึกตอนออฟไลน์ แอปจะเติมข้อมูลให้เองเมื่อกลับมาออนไลน์
- **ชั้นหนังสือ 3D:** มี 11 ห้องให้เลือก
  - ห้องใต้หลังคาวันฝนตก, ห้องเช่าเมืองนีออน, ห้องสมุดเก่า, บ้านญี่ปุ่น, บ้านต้นไม้, สถานีอวกาศ, หอคอยพ่อมด, ตู้นอนรถไฟกลางคืน, ห้องใต้ทะเล, คาเฟ่, สตูดิโอมินิมอล
  - ปรับแต่งได้: สีและวัสดุชั้น, จำนวนชั้น, กลางวัน/กลางคืน, ของตกแต่ง (บางชิ้นปลดล็อกจากอชีฟเมนต์)
  - เรียงอัตโนมัติได้ตามแนว ซีรีส์ ผู้แต่ง สถานะ วันที่เพิ่ม หรือสีปก
  - สลับเป็นมุมมองรายการ 2D ได้
- **อ่าน:** มีโหมดจับเวลาให้เลือก
  - จับเวลาปกติ
  - แค่ 5 นาที
  - Pomodoro
  - คว่ำมือถือ: จอดำเพื่อประหยัดแบต หยิบมือถือขึ้นมาเวลาจะหยุด
  - ถ้าลืมหยุดจับเวลา แอปจะถามให้แก้เวลา
  - กรอกรอบที่อ่านย้อนหลังได้ และแก้หรือลบรอบที่บันทึกไปแล้วได้
- **ความคืบหน้า:**
  - streak ที่ขาดได้เดือนละ 2 วันโดยไม่หาย
  - XP และเลเวล, อชีฟเมนต์ 24 อัน
  - เป้าหมายรายปี, สถิติรายเดือนและรายปี
  - การ์ดแชร์ลงสตอรี่ (อ่านจบรอบ, จบเล่ม, คำคม, สรุปเดือน/ปี)
- **ผู้ช่วย AI:**
  - สร้างข้อความจากข้อมูลชั้นหนังสือ เช่น ควรอ่านเล่มไหนก่อน (มีรูปรวมปกพร้อมหมายเลขให้แนบด้วย), วางแผนอ่านให้จบ, ทดสอบความเข้าใจ, สรุปโน้ต, แนะนำเล่มต่อไป, ชวนคุยเรื่องหนังสือ
  - สร้างเทมเพลตของตัวเองได้
  - มีปุ่มสุ่มเล่มให้
- **คำคม:** ถ่ายรูปหน้าหนังสือ แอปอ่านตัวหนังสือให้ แล้วเก็บเฉพาะประโยคที่ชอบ
- **อื่นๆ:**
  - สองภาษา ไทย/อังกฤษ
  - เสียงสังเคราะห์ในแอป (ไม่ต้องมีไฟล์เสียง)
  - เตือนให้อ่านผ่านไฟล์ปฏิทิน (.ics)
  - ส่งออก/นำเข้าไฟล์ `.ireadbook`

## รันบนเครื่อง

ต้องมี Node.js 18 ขึ้นไป

```bash
npm install
npm run dev      # เปิดที่ http://localhost:5173
```

## สร้างไฟล์สำหรับขึ้นเว็บ

```bash
npm run build    # ได้โฟลเดอร์ dist/
```

ในโฟลเดอร์ `dist/` คือไฟล์ทั้งหมดของแอป เอาขึ้นโฮสต์ฟรีได้ แต่ต้องเป็นลิงก์ **https** กล้องและการติดตั้งแอปถึงจะใช้ได้

- **Netlify (ง่ายที่สุด):**
  1. เปิด https://app.netlify.com/drop
  2. ลากโฟลเดอร์ `dist` ไปวาง
  3. ได้ลิงก์ทันที
- **GitHub Pages:**
  1. push โปรเจกต์ขึ้น GitHub
  2. อัปโหลดไฟล์ใน `dist/` ขึ้น branch `gh-pages`
  3. เปิด Pages ในหน้าตั้งค่าของ repo
  - แอปใช้ path แบบ relative และ hash routing เลยวางไว้ใน subfolder ไหนก็ได้

## ติดตั้งลงมือถือ

- **Android (Chrome):** เปิดลิงก์ แล้วกด "ติดตั้ง" ที่หน้าตั้งค่าของแอป หรือจากเมนู Chrome → "เพิ่มลงในหน้าจอหลัก"
- **iPhone (Safari):** เปิดลิงก์ แล้วแตะปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
  - ควรติดตั้งลงหน้าจอ เพราะถ้าไม่ติดตั้ง Safari อาจลบข้อมูลเมื่อไม่ได้เปิดนานๆ

## ย้ายเครื่อง

1. เครื่องเก่า: ตั้งค่า → ส่งออกไฟล์สำรอง
2. เครื่องใหม่: เปิดแอปครั้งแรก → "ย้ายมาจากเครื่องเก่า? นำเข้าไฟล์สำรอง"
   - ถ้าเคยใช้แอปในเครื่องนั้นแล้ว: ตั้งค่า → นำเข้าไฟล์สำรอง แล้วเลือก "รวม" หรือ "แทนที่ทั้งหมด"

## ทดสอบ

```bash
npm test         # unit tests (Vitest)
npx playwright test   # end-to-end: รันบน production build (ต้อง npm run build ก่อน)
```

## โครงสร้างโค้ด

| โฟลเดอร์ | หน้าที่ |
|---|---|
| `src/domain/` | การคำนวณล้วน (streak, XP, สถิติ, ซีรีส์, การเรียงชั้น, พรอมต์, อชีฟเมนต์) มี unit test ทุกไฟล์ |
| `src/db/` | ฐานข้อมูลในเครื่อง (IndexedDB ผ่าน Dexie) |
| `src/lookup/` | บาร์โค้ด, OCR (Tesseract.js ไทย+อังกฤษ เก็บไฟล์ภาษาไว้ใน `public/ocr`), ค้นข้อมูลหนังสือ |
| `src/image/` | ดัดภาพปกจาก 4 มุม, หามุมอัตโนมัติ, ปรับแสง, สีหลัก |
| `src/rooms/`, `src/three/` | ห้อง 3D และชั้นหนังสือ (three.js / react-three-fiber) |
| `src/share/` | วาดการ์ดแชร์และรูปรวมปก |
| `src/screens/` | หน้าจอต่างๆ |
| `docs/` | สเปกและแผนการพัฒนา |
